# Front

Physical HEX1000 keypad and MAX7219 controller. The X_eTaL model defines
row scanning, eight stable scans of debounce, key handshakes, second
consecutive equals as Clear, digit capture and the serial display stream.

Use `"fr:" u_se< "Front"`. Run `just demo-lib Front keys` or
`just test`. [Reference](docs/README.md) and
[physical wiring](../../docs/wiring.md).
