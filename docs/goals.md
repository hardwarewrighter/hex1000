# Goal

Build a standalone HEX1000 calculator on the Tang Nano 1K: a 4x4 hex
keypad, four operator keys and an eight-digit MAX7219 display, with
X_eTaL defining every result. The 4K is a fallback if the complete panel
does not fit. See plan.md for work order and hardware.md for interfaces.

Panel contains a mathematical layout suitable for a future case or
renderer; this repository does not yet include the source project's
3D mockup renderer.
